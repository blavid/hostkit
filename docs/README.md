# HostKit docs

Canonical Phase 0 / M1 product spec lives in the working tree at
`/workspace/product/SPEC.md` until it is copied here as `docs/SPEC.md`.

## Placeholder convention

Use `{{LIKE_THIS}}` for any value that must not appear as a real secret in git
or chat: `{{WIFI_PASSWORD}}`, `{{WIFI_SSID}}`, `{{PROPERTY_ADDRESS}}`,
`{{GUEST_PATH_KEY}}`, etc. Real values are Worker secrets / vault only.
